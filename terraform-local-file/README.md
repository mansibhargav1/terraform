# Terraform Local File Example

This project demonstrates how to create a **local file using Terraform**.

## 📁 Project Structure

terraform-local-file/
terraform-local-file/ 
├── main.tf 
├── local-file.txt 
├── README.md 

## 🚀 What This Terraform Script Does

- Uses **Terraform local provider**
- Creates a file called `local-file.txt`
- Adds custom content inside the file

## ⚙️ Steps to Run

1. Initialize Terraform

terraform init

2. Check execution plan

terraform plan

3. Apply configuration

terraform apply

## 📄 Output

Terraform will create a file:

local-file.txt

with the content defined in `main.tf`.
